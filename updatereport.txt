16. BRAIN.PY — Global Token-Bucket Rate Limiter (NEW)
------------------------------------------------------
File: nvidia_apex_trader/core/brain.py

- ADDED: `_wait_for_nvidia_rate_limit(api_key)` — thread-safe pre-flight rate limiter
- Enforces: 30 RPM max per key (below NVIDIA's 40 RPM limit, 25% headroom)
- Enforces: 2.5-second minimum gap between calls on the same key
- Proactive sleep: if rolling 60s window is full, sleeps until oldest call expires
- Per-key tracking: separate counters for NVIDIA_API_KEY and NVIDIA_API_KEY_2
- Prints warnings when RPM approaches 20/30

Impact: Eliminates burst traffic. Every NVIDIA call is pre-checked before hitting
         the network. No more 429s from rapid-fire agent calls.


17. BRAIN.PY — Jittered Exponential Backoff on 429
----------------------------------------------------
File: nvidia_apex_trader/core/brain.py

- OLD: Sleep time = 2^attempt (deterministic, causes thundering herd)
- NEW: Sleep time = 2^attempt + random(0.5, 2.0) seconds
- Max sleep capped at 15s (was 10s)

Impact: Prevents all retry attempts from syncing up and slamming the API at once.


18. BRAIN.PY — AI Consensus Response Cache (NEW)
------------------------------------------------
File: nvidia_apex_trader/core/brain.py

- ADDED: 45-second cache for evaluate_market results
- Cache key: hash of symbol + price_bucket + market_data[:500] + force_run flag
- Price bucket rounds to nearest $2 to avoid cache misses on tiny wiggles
- Cache hit skips ALL 3 NVIDIA agent calls entirely
- Cache miss stores result after consensus completes

Impact: If price hasn't moved meaningfully in 45s, zero NVIDIA calls are made.
         This alone can reduce API usage by 50-70% during quiet markets.

================================================================================
HOW THE RATE LIMITER WORKS (Summary)
================================================================================

Every NVIDIA NIM call now flows through 3 layers of protection:

  LAYER 1 — AI Cache (brain.py)
    → If market state unchanged in 45s: ZERO calls. Return cached consensus.

  LAYER 2 — Global Token Bucket (brain.py fetch_nvidia_sync)
    → Before every request: check per-key RPM + minimum gap
    → If limit hit: sleep proactively until safe
    → If 429 received: jittered exponential backoff (no thundering herd)

  LAYER 3 — Server RPM Gate (server.py trap loop)
    → Trap loop checks if consensus already used quota
    → If RPM > 25: skip traps until next cycle

EXPECTED RESULT: 429 errors eliminated. API calls stay comfortably under
NVIDIA's 40 RPM limit with 25% headroom. No ban risk.
